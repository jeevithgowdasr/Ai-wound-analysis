# AI Wound Analysis & Monitoring Platform (WoundSense AI)

## Automated Wound Monitoring & Analytics Platform

## Project Overview

WoundSense AI is a digital health proof-of-concept designed to assist patients and clinicians in tracking chronic wound healing. By leveraging smartphone computer vision, the system provides objective, consistent measurements of wound size and tissue composition.

## Core Features

1. **Smart Capture:** Guided image acquisition with quality checks.
2. **Auto-Segmentation:** AI-driven wound boundary detection.
3. **Tissue Analytics:** Classification of Granulation, Slough, and Necrotic tissue.
4. **Healing Trends:** Visual graphs of progress over time.
